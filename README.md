# fengzhilanai.github.io

风之岚科技的统一服务入口，连接个人、团队与组织的 AI 诊断、共创、试点与项目落地服务。

## 页面内容

- `/`：品牌介绍与三类服务路径入口
- `/solo/`：个人创业者与小团队服务
- `/business/`：中小企业与部门团队服务
- `/public-sector/`：政企、园区、协会与高校组织方服务

## 本地预览

这是一个无构建步骤的静态网站，可在仓库根目录运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/>。

## 发布

仓库名为 `fengzhilanai.github.io`，GitHub Pages 发布后统一入口地址为：

<https://fengzhilanai.github.io/>

建议在仓库的 **Settings → Pages** 中选择 `main` 分支和 `/ (root)` 目录。
